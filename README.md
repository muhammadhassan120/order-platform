# Order Platform

AWS event-driven order processing demo with:

- Node.js Order API and built-in UI
- ECS Fargate, ALB, CloudFront, RDS PostgreSQL
- SQS, Lambda, DynamoDB, S3 invoices, SES, SNS
- Jenkins pipelines for app, Lambda, and optional Terraform deployment

Start with [CLIENT_HANDOFF_GUIDE.md](CLIENT_HANDOFF_GUIDE.md). Operational notes are in [docs/runbook.md](docs/runbook.md).
